# 基论港问题场方法模型

本文件是正式 Skill 的方法模型。它由可回查直接材料、跨材料综合、第三方参考基础和项目的跨来源系统综合编译而成。它是项目方法，不归属于任何单一人物。

## 六种关系

### 母问题

用一句疑问说明：哪一个分歧一旦改变，理解、责任或选择会随之改变。中立分析或多方材料中，母问题必须容纳至少两个有材料支持或明确标为假设的可理解答案。单方任务只检查用户立场是否真正回答母问题，不补写缺席对方。

### 共同对象

恢复题面、现实对象、行动、角色和语境，区分哪些相同、哪些未知。定义、类比和框架必须同时说明突出什么、排除什么。

### 竞争解释

每个当前立场都要公开“材料／前提—连接—结果／价值／行动”。允许事实解释、价值解释、制度方案与角色处境并存，只保留真正改变母问题的解释。实际主张必须有可回查材料；系统构造的竞争解释必须标为假设。

### 对抗残留

内部检验或实际攻击后，标记失效、削弱、范围缩小、仍成立或转为未知。反例、替代解释和质询承认必须指出改变了哪条连接。对方失败不自动证明己方。

### 未知责任

列出仍缺的事实、连接或尺度，说明谁想从未知取得利益、未知时谁承担不利益。新内容是否有效取决于对方是否有真实回应机会，而不只取决于出现辩位。

### 比较选择

检查对象是否合题、是否有代表性、单项是否成立、是否可共量，以及还剩哪些质性差异。暂时选择要说明决定性差异、承认的对方价值、承担的代价和失效条件。

## 一次工作节奏

每项任务只执行一次压缩—对抗—回收。压缩确定最少问题场；对抗只测试决定性连接；回收只保留检验后的残留。关键检验是默认后台动作，不自动变成立论稿、改稿或其他任务的可交付段落；需要展示时，直接说明改变判断的条件及剩余结论。真实新增材料或明确纠错只更新受影响关系，不重做无关部分。

## 任务观察窗口

任务适配只改变观察窗口，不改变模型本体：

| 任务 | 优先观察 |
|---|---|
| 辩题分析 | 共同对象、实际或标明假设的竞争解释、根本分叉、责任与改变判断的关键条件 |
| 论点诊断 | 最早且最有杠杆的断裂、最小修改、修改后残留 |
| 稿件修改 | 用户母问题和立场、受损连接、必要局部重写 |
| 立论稿生成 | 用户持方、定义与标准、完整自方连接、证明责任；不自动攻防 |
| 攻防设计 | 已有对方材料的实际连接，或明确标记的可能路线、分支与检验后残留 |
| 质询 | 对象、前提、连接、条件回答分支、质询终点与实际利益回收 |
| 自由辩论 | 赛制与实时局势、少量关键战场、推进或拆解用途、条件分支、队友成果衔接、退守条件与整体回收 |
| 总结 | 场上已有材料的残留、尺度、代表性、决定性差异与未完成责任 |
| 复盘 | 母问题更新、策略收益、终局不足、成本与迁移 |
| 评判 | 赛事规则、记录完整性、场上残留、实际回应机会、整体内容与环节表现及程序影响的分离、争议前提与条件性结论 |

自由辩论的默认准备单位是问题方向、论证储备、己方难点、退守条件和团队衔接，不是预设对方配合的逐句脚本。真实回答优先于赛前预测；局部短打只有在改变关键连接并回到整体立论时才形成稳定利益。具体打法受赛制、时间、队伍配置和实时局势约束。

评判没有跨赛制通用的唯一传统。赛事规则优先；系统只提供最低共同框架：还原场上主张与连接，检查实际回应和证明责任，比较交锋后的残留，并公开决定性理由。整体内容判断、个人或环节表现、程序与媒介影响分开记录，是否合并由赛制决定。场外常识、推定利益、阶段评分和晚出内容等争议项若足以改变结果，必须声明采用的前提；记录不足时保留条件性或不确定结论。

## 外部事实进入问题场

资料只在说明其证明事项和用途等级后进入“材料／前提—连接—结果”。核心锚点、条件性有效、仅作线索或背景、不推荐使用是用途判断，不是按文献名称排序。新闻案例只能承担事件发生、可能性或有限机制；没有总体资料时不得承担普遍性和趋势。尚未核验、单方发布或互相冲突的事实进入未知责任，不得靠表达升级。

## 高风险判断记录

| 字段 | 作用 |
|---|---|
| 判断 | 当前使用的主张或选择 |
| 来源层 | 可回查直接材料／跨材料综合／第三方参考基础／系统综合／用户材料与反馈 |
| 支持连接 | 材料为什么支持到当前判断 |
| 当前状态 | 待证明／暂时成立／削弱／未决定／失效 |
| 条件与反例 | 成立范围及可能改变判断的内容 |
| 整体影响 | 对母问题和最终选择的改变 |

记录数量不等于证据强度，重复、转引或互相依赖的材料不得重复计权。

## 方法动作而非固定风格

- 恢复被题面或流行说法压平的对象与语境。
- 用递进追问寻找真正改变判断的条件。
- 对方实际材料确有成立部分时予以承认，再检查其范围与决定性。
- 用反例和替代解释限制结论，而非追求一句击倒。
- 类比或隐喻打开关系后，反查不相似处与遮蔽部分。
- 比较交锋后的残留，回到选择者承担的责任。
- 先压缩结构，再为听众解压缩关键连接。

这些是项目经跨材料检验后保留的可迁移判断与表达动作，不是口癖、固定顺序，也不代表任何被引用或致谢者对新议题的立场。
