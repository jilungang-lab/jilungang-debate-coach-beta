# 来源与发布审计边界

## 来源层

- 本人原作：可支持张子龙明确表达，但只在原语境和核验范围内使用。
- 本人原作层综合：可描述跨材料稳定动作，必须明确是综合结果。
- 第三方参考基础：提供论证、举证责任、质询、比较、裁决、训练和研究能力，不得归给张子龙。
- 系统综合：跨来源关系、问题场模型、任务映射和输出选择。
- 用户材料与反馈：用户立场、原稿、偏好和人工决定。

比赛持方、作品评论和具体公共议题立场只在原语境使用。不能从方法相似、观点相近或材料并列推断作者关系。

对方实际主张也属于材料归属判断：只有用户提供的稿件、赛场记录或其他可回查材料可以支持。系统为中立分析或攻防准备构造的竞争解释，必须标为系统假设，不能写成对方已经提出。

## 演变

发布日期只提供时序线索。只有材料处于可比语境且存在明确修正证据，才能称为观念演变。RC1 只接受已经冻结的四项窄范围演变：价值衡量中的重要性、裁判处理未核事实、对定义的理解、好立论的判断标准。使用时仍需说明可比语境，不得扩张为整体思想阶段论。

## 材料状态

- 黑岛附件由用户确认属于本人原作，可以进入本人原作层理解；其时间状态仍按核验记录处理。
- OCR、图片、转录和附件只有明确标记逐字核验时，才能作逐字引述或声称全部核验。
- 正文不足、作者关系不明或核验状态不足的材料只能保留为缺口，不能从标题补写内容。

## 第三方参考的实际角色

参考资料用于检查：隐含连接、举证责任、已有材料中的强回应、回应机会、方案与替代选择、实施成本、裁判尺度、训练迁移与退出边界。引用参考书时说明它检查了哪条连接或程序；“书中也提到”本身没有证明力。

为当前任务查找的外部书籍、研究、官方资料和新闻，都属于第三方事实基础，不构成张子龙本人观点。中国政务发布只能证明该机关作出了什么发布，以及其职责范围内确认了什么；不自动证明完整真相或责任归属。国际报道可作补充，但不得绕过可取得的中国原始文件。

V10 当前清单共有 338 条来源路径，其中 298 条可进入蒸馏：259 条本人原作路径、39 条第三方参考路径。新增完成处理的十条长篇第三方资料只增强或收窄参考基础：尤其支持准备层与现场层分离、任务阶段依赖真实输入、同层比较及表达不升级证据。它们不构成张子龙本人观点，也不授权预设对方“最强论证”。六条正文不完整资料继续延后，一条重复路径继续排除。

## 发布边界

- 正式模型不依赖运行时全文检索、向量数据库、BM25、GraphRAG、知识图谱、思想卡或任务图。
- 旧 Skill 和 RC0 只作为回滚与回归基线，不参与运行时生成。
- 不冒充张子龙、不复制口癖、不替他生成未公开的新立场。
- 不能声称全部页面和所有平台原帖已经逐字核验。
- 私有语料、逐份蒸馏和长篇摘录不得进入公开 Git 或正式 Skill。

## 已知限制

- RC1 在来源覆盖、后验生成、对象校正、未知责任、来源贡献和演变审计上相对 RC0 有实质改进。
- 旧 Skill 在自动任务图、运行时检索接地、语料消融和机器回归方面更成熟；这些能力作为回滚基线保留，不伪装成 RC1 的优势。
- 发布回归主要验证推理结构和教练动作，不替代对现实事实的外部研究。
